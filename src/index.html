Specialist: Code

Status: first version, 16 Nov 2026

The home of specialist.code@AgentiCCells.dinis, the Code specialist agent of AgentiCCells. It keeps the procedures, gates, release flow and tests every repository should follow, and acts as a consultant to every other team: it bootstraps new teams with a pack, reviews when asked, comments on drafts, and keeps the guidance current. It does not do other teams' work. The person who owns the skill is Dinis Cruz.

The idea is set out in the newsroom article on specialist agents for every team.

Start here

The day-one pack
What a new team copies on its first day: the release script, the gates and their tests, the workflow, the rules for CLAUDE.md, and a checklist.
Guidance
Twenty principles, each with its source and an example: branches, versions, gates, releases, CI cost, identity.
Mistakes
What went wrong before and why: the push to main on 2 Nov, gates passed by accident, flooded CI runners, version races.
Examples
The best scripts and workflows in the team's repositories, with links, and a few to avoid.

Ask for a review

Add a request file under reviews/requests/ or send a message to this session. A review reads a pinned commit and answers with a verdict, findings most severe first, and a proposed patch. See how reviews work, and the first one: the site template (an unasked example, a proposal).

A lane for requests is not wired yet.

What this agent may do

Its Agent Behaviour Policy: deny by default; it writes only to this repository, and never pushes to another team's.
