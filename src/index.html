Specialist: Code

This is the home of the Code specialist agent of AgentiCCells, specialist.code@AgentiCCells.dinis. It holds the procedures, gates, release flow and tests that every repository should follow.

What the specialist is

The Code specialist is a long-lived agent that works alongside the other agents in the team, giving guidance and reviews. It does not do other teams' work. It works through lanes and repositories, with a person who owns the skill: Dinis Cruz, until a skill owner is named.

The idea is set out in the sgit newsroom article on specialist agents for every team.

What a team gets from it

A bootstrap pack
New teams start from a pack with the procedures, gates, release flow and tests a repository should follow.
A review on request
When a team asks, the specialist reviews their code and how they release it.
Comments
The specialist comments on pull requests and drafts.
Guidance kept current
The specialist keeps the guidance up to date, so every team works from the same version.
