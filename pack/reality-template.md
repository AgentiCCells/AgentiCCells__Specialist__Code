# REALITY.md template

Copy to `REALITY.md` at the root and keep it true. A thing not written here does not exist.

```
# REALITY.md: what exists now

Checked <date> by <role@AgentiCCells.person>.

## Live
- <address>, version at /version.json (last checked: vX.Y.Z on <date>).

## Enforced (a check or setting stops it)
- Gates in CI before deploy: <list>.
- <setting, for example: main protected; Pages environment limited to dev>.

## Kept by habit (a rule, nothing stops it)
- <for example: no agent pushes to main (no branch protection yet)>.

## Proposed, not built
- <item, with where the proposal lives>.
```
